# 钉钉扫码打卡顶栏对齐个人网站设计

## 目标

将 SWU钉钉扫码打卡的顶栏视觉和宽度与个人网站顶栏保持一致，并移除页面中的 `SWU Campus` 英文文案。

## 修改范围

- 顶栏外层采用个人网站相同的吸顶定位、响应式页边距和顶部间距。
- 顶栏内容区统一为 `max-w-5xl`，并沿用个人网站的高度、圆角、边框、半透明背景、阴影和模糊效果。
- 左侧品牌区改为 28px 品牌图标和单行中文名称“SWU钉钉扫码打卡”。
- 保留钉钉站点现有的状态徽标、刷新与退出等右侧操作。
- 删除顶栏和维护页中的 `SWU Campus`，不改动其他业务文案。
- 登录页、已登录页和维护页共享同一顶栏实现，三种状态下宽度一致。

## 实现方式

在 `components/app-shell.tsx` 内调整现有 `Brand` 与 `SiteHeader`，让顶栏自行负责页面级定位和宽度；各页面主体继续使用原有内容宽度，避免扩大二维码、信息卡片等业务区域。同步调整页面根容器的顶部布局，防止顶栏外边距与现有内边距叠加。

不抽取跨仓库共享组件，因为两个项目的顶栏右侧功能不同，引入跨仓库依赖会扩大维护范围。

## 验收条件

- 顶栏内容区与个人网站均为 `max-w-5xl`。
- 顶栏在移动端和桌面端的高度、横向页边距及顶部间距与个人网站一致。
- 页面源码和渲染结果中不再出现 `SWU Campus`。
- 登录、已登录和维护状态原有交互不受影响。
- 相关组件测试、lint、TypeScript 类型检查和项目测试通过。
