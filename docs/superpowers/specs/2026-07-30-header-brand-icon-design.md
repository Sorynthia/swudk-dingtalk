# 顶栏品牌图标替换设计

## 目标

将站点现有 favicon 用作顶栏左上角的品牌图标，并将品牌主文字从“西大寝签”改为“钉钉扫码打卡”。

## 实现范围

- 在 `src/components/app-shell.tsx` 的 `Brand` 组件中移除 `GraduationCap` 图标。
- 使用 Next.js `Image` 组件显示 `/icon.svg`，复用 `src/app/icon.svg` 这一站点图标资源。
- 保持现有图标容器的尺寸、圆角、间距和响应式布局不变。
- 保留辅助品牌文字“SWU Campus”。
- 将中文品牌主文字改为“钉钉扫码打卡”。

## 资源与数据流

浏览器通过 `/icon.svg` 读取 Next.js App Router 管理的站点图标。顶栏不复制或内联 SVG 内容，确保浏览器 favicon 与页面品牌图标共用同一资源。

## 可访问性

顶栏图标属于品牌文字旁的装饰元素，使用空替代文本，避免屏幕阅读器重复朗读品牌名称。

## 验证

- 更新组件测试，确认顶栏显示“钉钉扫码打卡”且不再显示原主文字。
- 运行相关 Vitest 测试。
- 运行 TypeScript 类型检查和 ESLint。
